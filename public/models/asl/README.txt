ASLNow! pretrained TensorFlow.js model.
Files: model.json and group1-shard1of1.bin.
Recognises static ASL fingerspelling letters A-Y except movement-dependent J and Z.
J and Z are not supported by this static model.
The upstream model is MIT-licensed: https://huggingface.co/sid220/asl-now-fingerspelling
This integration has not been validated for real-world accuracy; do not describe it as full ASL translation.
